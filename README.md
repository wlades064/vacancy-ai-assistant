# Vacancy AI Assistant

Скрипт ищет вакансии на hh.ru, Habr Career, SuperJob и ArbiHunter, отбрасывает неподходящие позиции, анализирует оставшиеся вакансии с помощью GigaChat, формирует сопроводительные письма и сохраняет результат в Google Sheets. После завершения он отправляет уведомление в Telegram.

## Что попадает в таблицу

Для каждой подходящей вакансии сохраняются:

- название вакансии и компания;
- требуемый опыт, город и возможность удалённой работы;
- источник и дата публикации;
- оценка соответствия и вердикт GigaChat;
- подробный анализ, сопроводительное письмо и ссылка.

Перед каждым запуском лист очищается и заполняется заново. Учитываются вакансии не старше семи дней. Вакансии не из Саратова или Энгельса сохраняются только при наличии удалённого формата.

## Настройка

Скрипту нужны следующие переменные окружения (в GitHub Actions они задаются как repository secrets):

| Переменная | Назначение |
| --- | --- |
| `GIGACHAT_KEY` | Ключ доступа к GigaChat |
| `SUPERJOB_API_KEY` | Secret key приложения SuperJob. Без него источник пропускается |
| `GIGACHAT_MODEL` | Модель GigaChat; по умолчанию `GigaChat-2` |
| `GIGACHAT_SCOPE` | Scope API; по умолчанию `GIGACHAT_API_PERS` |
| `HABR_ENABLED` | Включает поиск на Habr Career; по умолчанию `true` |
| `HABR_PAGES_PER_QUERY` | Число страниц Habr Career для каждого запроса; по умолчанию `2` |
| `GOOGLE_CREDENTIALS` | JSON сервисного аккаунта Google в одной строке |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID чата для уведомления |

Сервисному аккаунту Google нужно предоставить права редактора на таблицу. Идентификатор таблицы задаётся константой `SPREADSHEET_ID` в `main.py`.

## Локальный запуск

Требуются Python 3.13 и Google Chrome.

```bash
python -m venv .venv
```

Активируйте окружение и установите зависимости:

```bash
pip install --requirement requirements.txt
```

Задайте переменные окружения и запустите:

```bash
python main.py
```

## Автоматический запуск

Workflow `.github/workflows/weekly.yml` запускает скрипт каждый понедельник в 11:00 UTC. Его также можно запустить вручную на вкладке **Actions** с помощью `workflow_dispatch`.

## Фильтрация

Поисковые запросы и допустимые города находятся в `main.py`. Правила проверки названий вынесены в `vacancy_filters.py`:

- `search_queries` — поисковые запросы;
- `habr_search_queries` — отдельные запросы для Habr Career;
- `ai_search_queries` — отдельные запросы по ИИ, AI Automation, LLM и AI-агентам;
- `RELEVANT_KEYWORDS` — обязательные фрагменты в названии;
- `EXCLUDE_KEYWORDS` — исключающие слова и фразы;
- `EXCLUDE_COMPANIES` — исключаемые работодатели;
- `local_cities` — локальные города.

Сравнение стоп-слов не зависит от регистра, различий `е/ё`, вида дефиса и лишних пробелов.
Названия с маркерами `AI`, `ИИ`, `LLM`, `GenAI`, `нейросети`, `AI-агенты`, `n8n`, `MCP` и `RAG` считаются релевантными. Слова «инженер» и «разработчик» сами по себе больше не исключают AI-вакансию.
Удалённый формат проверяется как на странице вакансии, так и в карточке поисковой выдачи. Это защищает результаты от изменений разметки hh.ru.
Вакансии с опытом от трёх до шести лет исключаются при разных вариантах написания диапазона. Категории Senior и Lead на Habr Career также исключаются. Если одна компания размещает вакансию с одинаковым названием в нескольких городах или на разных источниках, в таблице остаётся одна запись. При выборе бот отдаёт приоритет Саратову, затем городам московского и самарского времени.

Если hh.ru возвращает слишком много сетевых ошибок или найдено меньше 30 исходных вакансий, запуск завершается без изменения Google Sheets. Порог можно настроить переменными `MIN_COLLECTED_VACANCIES` и `MAX_HH_FAILURE_RATE`.

Habr Career подключён как дополнительный источник через публичные страницы поиска. Ошибка Habr Career не останавливает рабочий поиск по hh.ru. Ошибка или недостаточное число результатов hh.ru по-прежнему останавливает запись, чтобы не заменить таблицу неполной выборкой.

SuperJob использует [официальный API](https://api.superjob.ru/) и те же поисковые запросы, что hh.ru. Для каждого запроса загружается до пяти страниц по 100 вакансий за семь дней. Достижение лимита отмечается в журнале. Секрет `SUPERJOB_API_KEY` передаётся через GitHub Actions. При отсутствии ключа, отказе в доступе или сетевой ошибке остальные источники продолжают работу.

К SuperJob применяются общие фильтры и анализ GigaChat. Среди прошедших фильтры вакансий при совпадении названия и компании с hh.ru запись SuperJob исключается до анализа, независимо от города и порядка поступления. Сравнение учитывает регистр, пробелы, варианты дефисов и `е/ё`. Для остальных записей сохраняется прежний приоритет городов. Если компания неизвестна, записи разных источников автоматически не объединяются.

ArbiHunter собирается с публичных HTML-страниц без API и авторизации. Сбор проходит выдачу постранично (до 30 страниц), ищет релевантные названия локально и загружает описания подходящих вакансий за семь дней. Применяются общие фильтры, анализ и приоритет hh.ru при совпадении компании и названия. Работодатели под NDA считаются неизвестными и не объединяются между собой. Ошибка разметки или HTTP-доступа останавливает этот источник; остальные продолжают работу. CAPTCHA и ограничения доступа не обходятся.

Этот способ подключения не соответствует предоставленным владельцем проекта условиям ArbiHunter: они требуют публичный API, ограничивают использование публичной агрегацией и запрещают анализ. HTML-сбор не отменяет эти условия. Интеграция добавлена по явному запросу владельца проекта; разрешение ArbiHunter не получено.
